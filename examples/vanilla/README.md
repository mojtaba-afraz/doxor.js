# doxor.js vanilla example

A tiny todo list using doxor.js with Vite, no framework.

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/mojtaba-afraz/doxor.js/tree/main/examples/vanilla)

```sh
npm install
npm run dev
```

Use it as a starting point for bug reproductions: fork it on StackBlitz, change `main.js` until the bug shows up,
and share the link in your issue.
